# HandleScout
A Python-based tool with custom REST APIs that checks real-time username availability across Instagram, TikTok, X, and YouTube. Features a responsive front end (HTML/CSS/JS) with input validation and real-time feedback. Automates multi-platform lookups to save time for content creators and brands.

✅ Fast, automated username checks across 4 major platforms

🌐 Clean, responsive front end using HTML, CSS, and vanilla JavaScript

✍️ Real-time input validation and feedback for a smooth user experience

⚙️ Backend powered by Python scripts and custom API integrations

🎯 Built to save hours of manual checking and improve branding workflows
